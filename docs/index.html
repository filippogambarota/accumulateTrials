This repository contains the data, R code, analysis outputs, and Quarto documents used for the paper “The More the Trials, the Stronger the Effect”. Fact or Myth? Evidence from Classical Experimental Psychology Paradigms.

The project studies how progressively adding trials changes effect estimates, uncertainty, variance components, standardized effect sizes, and test statistics in three repeated-measures experimental psychology paradigms: the Simon task, the Spatial Numerical Association of Response Codes (SNARC) task, and a task-switching task.

The repository is also structured as a small R package. This makes the cleaned datasets and helper functions available through standard R package tooling while keeping the full analysis pipeline in scripts.

Repository structure

  • R/: documented helper functions used by the analyses, including accumulate_trials(), block2trial(), westfall_d(), and check_lmer_fit().
  • data/: processed datasets distributed with the package. They can be loaded with data("simon"), data("snarc"), and data("tswitch").
  • data/raw/: raw task-level CSV files used to create the processed datasets. Private participant identifiers were removed before inclusion.
  • scripts/: executable analysis pipeline, from preprocessing to model fitting and participant-resampling analyses.
  • objects/: serialized .rds analysis outputs created by the scripts and used by the paper and supplementary materials.
  • paper/: Quarto source files for the manuscript (paper.qmd) and supplementary materials (supplementary.qmd), plus paper-specific plotting utilities and generated figure files.
  • shiny/: Shiny application and prepared .rds files for interactively exploring the cumulative-trial results.
  • man/: function and dataset documentation generated by roxygen2.
  • docs/: rendered website output, including the HTML/PDF manuscript and supplementary materials.
  • _extensions/: Quarto extensions used to render the website and paper formats.
  • _freeze/: Quarto freeze cache for reproducible rendering.
  • renv.lock and renv/: project dependency lockfile and renv infrastructure.
  • _quarto.yml: Quarto website configuration.
  • index.qmd: Quarto homepage; it includes this README to keep the website overview synchronized with the repository overview.
  • styles.css: custom CSS for the rendered Quarto website.
  • DESCRIPTION and NAMESPACE: R package metadata and exported objects.
  • accumulateTrials.Rproj: RStudio project file.
  • accumulateTrials.slurm: SLURM submission script for running the computationally intensive resampling step on a cluster.

Main datasets

The processed datasets have a harmonized trial-level structure with participant identifiers, condition labels, accuracy, reaction time, and cumulative trial index:

  • simon: preprocessed Simon task data.
  • snarc: preprocessed SNARC task data.
  • tswitch: preprocessed task-switching data.

Each dataset is documented. After loading the package, use ?simon, ?snarc, or ?tswitch for details on columns, preprocessing, and data provenance.

Important dataset-specific notes:

  • In the SNARC raw files, congruent and incongruent labels were inverted. The preprocessing script corrects this in the analysis condition column.
  • In the task-switching data, the analysis condition is derived from the raw Switch variable. Non-switch trials are coded as "c" and switch trials as "i" so that the downstream model code can use the same two-condition structure across tasks.

Analysis pipeline

Run the scripts from the project root in this order:

  1. scripts/01-pre-processing.R
    • Reads data/raw/*-raw.csv.
    • Harmonizes task variables, filters reaction-time outliers, removes low-accuracy participants, and saves data/simon.rda, data/snarc.rda, and data/tswitch.rda.
  2. scripts/02-cumulative-model.R
    • Loads the cleaned datasets.
    • Keeps correct trials with defined analysis conditions.
    • Creates cumulative-trial datasets starting at 32 trials and adding 5 trials at each step.
    • Fits mixed-effects models for raw and log reaction times.
    • Saves cumulative model outputs in objects/ and prepared Shiny data in shiny/.
  3. scripts/03a-resampling.R
    • Resamples participants within each task and cumulative-trial block.
    • Fits the main model repeatedly for participant sample sizes of 15, 50, and 100.
    • Uses 5,000 resampling iterations per condition.
    • Saves the nested output to objects/task_resampling.rds.
  4. scripts/03b-res-resampling.R
    • Flattens the nested resampling output.
    • Drops the repeated nested task data to create a lighter file, objects/task_resampling_lt.rds.

The resampling step is computationally expensive. It is intended for cluster execution; the provided SLURM script can be used as a starting point. In interactive mode, 03a-resampling.R runs only a reduced subset for testing.

Reproducing the project

Open the project through accumulateTrials.Rproj in RStudio, or open the repository root in another IDE.

Dependencies are managed with renv. If packages are missing, restore the recorded package versions with:

renv::restore()

Then load the package functions and datasets with:

devtools::load_all()

To rebuild the analysis outputs, run the scripts in the order listed above. To render the website, manuscript, and supplementary materials, run:

quarto render

Rendered files are written to docs/.

Paper and website

The Quarto website is configured in _quarto.yml. The homepage is index.qmd, which includes this README so that the repository overview and website overview stay synchronized.

The main manuscript and supplementary materials are in paper/:

  • paper/paper.qmd
  • paper/supplementary.qmd

The paper uses the apaquarto Quarto extension.

Shiny app

The Shiny app in shiny/app.R visualizes the cumulative-trial model results. It uses:

  • shiny/data.rds
  • shiny/data_by_subj.rds

These files are created by scripts/02-cumulative-model.R.

Package functions

The package exports four project utilities:

  • accumulate_trials(): creates cumulative datasets by progressively adding trials within participant.
  • block2trial(): converts cumulative block indices to trial counts.
  • westfall_d(): computes a Westfall-style standardized effect size from a mixed-effects model.
  • check_lmer_fit(): summarizes convergence and singularity diagnostics for lme4 models.

See the corresponding help pages after devtools::load_all(), for example ?accumulate_trials.
